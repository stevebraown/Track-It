# Quick Start: Get Your App on iPhone

## 🚀 Fastest Path (5 minutes)

### 1. Push to GitHub

```bash
# If not already a git repo
git init
git add .
git commit -m "Initial commit: Track It PWA"

# Create repo on GitHub.com, then:
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

### 2. Deploy to Vercel (Free)

```bash
npm i -g vercel
vercel
```

Follow prompts (defaults work fine). Your app is now live!

### 3. Install on iPhone

1. Open **Safari** on iPhone
2. Go to your Vercel URL (e.g., `https://your-app.vercel.app`)
3. Tap **Share** button (square with arrow)
4. Tap **"Add to Home Screen"**
5. Tap **"Add"**

**Done!** App is on your home screen. 🎉
